A step-by-step guide to creating your own blog with Jekyll-Now, LaTeX support, and pagination.


## Step 1: Fork Jekyll-Now

1. Go to [https://github.com/barryclark/jekyll-now](https://github.com/barryclark/jekyll-now)
2. Click the **"Fork"** button in the top-right corner
3. In your forked repository, click **Settings**
4. Rename the repository to "yourusername.github.io" (replace "yourusername" with your actual GitHub username)
5. Your blog will be live at "https://yourusername.github.io" in a few minutes!

## Step 2: Basic Configuration

Edit the "_config.yml" file in your repository:

```yaml
# Change your info
name: Your Blog Name
description: A cool description of your blog
avatar: https://github.com/yourusername.png  # Your GitHub profile pic URL

# Add these lines for pagination
paginate: 5
paginate_path: "/page:num/"
plugins:
  - jekyll-paginate

# Change to your info
footer-links:
  github: yourusername
  email: your-email@example.com
  twitter: yourtwitter  # optional

url: "https://yourusername.github.io"
baseurl: ""

# whatever esle you wish to adjust or add
```

## Step 3: Add LaTeX Math Support
Edit "_layouts/default.html" and add this **before** the closing "</head>" tag:

```html
<!-- MathJax for LaTeX -->
<script type="text/javascript" async
  src="https://cdnjs.cloudflare.com/ajax/libs/mathjax/2.7.7/MathJax.js?config=TeX-MML-AM_CHTML">
</script>
<script type="text/x-mathjax-config">
  MathJax.Hub.Config({
    tex2jax: {
      inlineMath: [['$','$'], ['\\(','\\)']],
      displayMath: [['$$','$$'], ['\\[','\\]']],
      processEscapes: true
    }
  });
</script>
```

## Step 4: Writing Your First Post

### File Naming Convention

Create files in the "_posts" folder with this exact naming pattern:

```
YYYY-MM-DD-file-name-of-your-post.md
```

**Examples:**

- "2025-06-01-my-first-post.md"
- "2025-06-02-article-5.md"
- "2025-06-03-javascript-tips.md"
### Adding Images 
1. Create an "images" folder in your repository root
2. Inside "images", create an "images_posts" folder for your blog post images 
3. Upload your images to "images/images_posts/" 
**Reference images in your posts:** 

```markdown 
![Alt text]({{ site.baseurl }}/images/images_posts/your-image.jpg) 
<!-- Or with a caption --> 

![My awesome diagram]({{ site.baseurl }}/images/images_posts/diagram.png) *Figure 1: This is my diagram caption* 

<!-- You can also use HTML for more control --> 
<img src="{{ site.baseurl }}/images/images_posts/photo.jpg" alt="Description" width="500">
```

### Linking to Other Posts

**Link to other articles you've written:**

```markdown
<!-- Method 1: Using post URL -->
Check out my [previous post about calculus]({{ site.baseurl }}/learning-calculus/)

<!-- Method 2: Using the full post path -->
Read more in my [JavaScript tips article]({{ site.baseurl }}{% post_url 2025-06-03-javascript-tips %})

<!-- Method 3: Simple relative link -->
See my [first post]({{ site.baseurl }}/my-first-post/) for more details.
```

**Link to external websites:**

```markdown
[Visit GitHub](https://github.com)
[Learn more about Jekyll](https://jekyllrb.com/)
```

### Post Structure

Every post must start with **YAML front matter** (the stuff between "---" lines):

```markdown
---
layout: post
title: "My Awesome Post Title"
---

# Your content starts here

This is my blog post content. I can write normal markdown here.

## Using LaTeX Math

Inline math: $x^2 + y^2 = z^2$

Display math:
$$
\int_{-\infty}^{\infty} e^{-x^2} dx = \sqrt{\pi}
$$

More content here...
```

### YAML Front Matter Explained

The YAML section (between "---") is **required** and contains metadata:

```yaml
---
layout: post          # Always use "post" for blog posts
title: "Post Title"   # The title that appears on your blog
date: 2025-06-01      # Optional: YYYY-MM-DD format (must match filename date)
tags: [tag1, tag2]    # Optional: categorize your posts
excerpt: "Short description"  # Optional: custom preview text
---
```
